# Plexus · Interface design

Status: **draft for Joe, being written.** Nothing here is built.

**What this document does:** it sets the design elements of the Plexus interface. The SYNAPSE Python panel (`C:\Users\User\SYNAPSE\python\synapse`) was studied as a design reference only. **Nothing from it is copied or imported**: no code, widget or class names, stylesheet text, assets or layout. Each borrowed idea is restated in Plexus's own terms, with the reason it fits.

**How decisions were made:** every design element has candidate options. TypeSafe's **Jev** model chose among them and routed each element to a Plexus surface, from the study's evidence and Plexus's rules. Jev also checked each element for copy risk: whether the option closest to the reference panel would amount to copying it. Code then applied one fixed policy on top: a pick with a high copy risk moves to the next option. Jev's raw probabilities are kept so any decision can be re-weighed.
