## Status note

These documents are the **August 2026 paper baseline** — the foundation the build starts from. The build direction has since been refined (standalone repository, Rust in the composition and orchestration layers, sibling projects as architectural references rather than dependencies); those refinements supersede the reuse framing in Blueprint §6 and Spec §1 where they conflict. The axioms, schemas, contracts, and acceptance tests stand as written.
