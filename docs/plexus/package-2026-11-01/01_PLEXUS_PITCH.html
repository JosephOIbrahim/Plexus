thirty seconds

Every production tool on earth seals a project in a jar. PLEXUS makes projects layers in one living stage, built on OpenUSD: a look-dev session and a shot can reference each other's live state while both are running, and changes cross the boundary the moment they're made.

Intelligence sits on the stage like a nervous system. Agents are dormant by default — a cheap predicate wakes one, it acts within a budget, it sleeps. Deterministic recipes handle the routine; a model call is the exception, never the hot path.

And the engine? ComfyUI is demoted from application to cargo hold — an interchangeable organ that executes what the network decides, with full provenance on every asset it returns. The stage describes everything and embeds nothing heavy: state, memory, and provenance live in the composition; pixels and weights stay on disk, referenced and hashed. The intelligence no longer lives in a graph editor. It lives in the composition.

The market already priced the principle: 2026's largest exit in this category went to sixteen people grounding AI in a production's own footage. PLEXUS grounds one level deeper — in the production's living structure — on a substrate that is nobody's product: OpenUSD, the ISO-track open standard its industry alliance now calls the 3D data layer for agentic AI. The spec, never a vendor.

the inversion — three moves

Jar → Layer

A project stops being a sealed file and becomes a layer stack other projects can reference — live, with arbitration by composition strength instead of locks.

Resident → Event-driven

No always-on copilot burning tokens. Neurons watch a scope, wake on a predicate, act once, go quiet. A nervous system, not a group chat.

Engine → Organ

Execution backends satisfy a small contract and become swappable. Every custom node the ComfyUI community ships becomes inherited capability, day one.
